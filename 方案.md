# 1. 产品介绍

## 1.1 产品定位

Modern WebShell Manager 是一个新一代 WebShell 管理工具。

目标：

* 替代传统菜刀类工具
* 提升大量 Shell 管理效率
* 提供现代化 UI
* 提供插件扩展能力
* 支持多种 Web 环境

核心能力：

```
Shell管理

文件管理

命令执行

数据库操作

协议扩展

插件扩展

请求调试

数据管理
```

# 3.2 安装方式

## Windows

下载：

```
WebShellManager.exe
```

双击运行。

默认目录：

```
C:\Users\<user>\Documents\WSManager
```

目录结构：

```
WSManager

├── config
├── database
├── plugins
├── logs
└── cache

```

---

## Linux

运行：

```bash
chmod +x wsmanager

./wsmanager
```

# 总结

现代 WebShell 管理工具不应该继续沿用：

```
菜刀:
一个页面一个密码

蚁剑:
插件增强客户端

冰蝎:
加密通信

哥斯拉:
Payload框架
```

而应该演进为：

```
                    Modern WebShell Manager

                             |

        ------------------------------------------------

        Shell Manager

        Protocol Engine

        Plugin Framework

        File Manager

        Terminal

        Database

        Debugger

        Workspace

        Audit Log

```

核心目标：

**做一个“VSCode + 浏览器开发者工具 + 蚁剑”的 WebShell 专用 IDE。**
